ПЕРО 1.6.1 — локальный ИИ для Chrome и Edge

УСТАНОВКА С ПОМОЩЬЮ БАТНИКА (Windows 10 22H2/11):
1. Распакуйте ВЕСЬ ZIP в папку; не запускайте файлы прямо из архива. Дважды щёлкните install-pero.bat рядом с manifest.json. Стандартная установка Ollama обычно не требует прав администратора; WinGet может запросить разрешение в зависимости от системы.
2. Батник найдёт Ollama или установит её через WinGet; если WinGet нет/он не сработал, скачает официальный OllamaSetup.exe и запустит его только после проверки цифровой подписи Ollama Inc. Затем установит только qwen3:4b-instruct-2507-q4_K_M (если модель уже есть, не качает повторно). Нужны интернет и место на диске: модель ~2.5 ГБ, установщик Ollama требует дополнительное место. Не закрывайте окно во время загрузки.
3. Укажите прежнюю папку расширения, если Перо уже установлено, чтобы не изменился ID; иначе Enter — копирование в %LOCALAPPDATA%\PeroExtension. В браузере включите режим разработчика и выберите «Загрузить распакованное расширение» (или «Обновить» для установленного из той же папки). Браузер не разрешает батнику выполнить этот шаг самостоятельно.
4. После загрузки скопируйте ID с карточки расширения и вставьте его в окно батника для настройки OLLAMA_ORIGINS только для Перо. Если ID пока нет, нажмите Enter и позже используйте команду из настроек панели. После изменения OLLAMA_ORIGINS полностью выйдите из Ollama через значок в трее, откройте снова и нажмите «Обновить список моделей» в панели.

РУЧНАЯ УСТАНОВКА (без батника):
1. Распакуйте этот ZIP в постоянную папку. Рядом с этим файлом должен лежать manifest.json.
2. В Chrome откройте chrome://extensions/ (Edge: edge://extensions/), включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку.
3. Нажмите значок «Перо» на панели браузера. В настройках (⚙) выберите локальную модель Ollama.
4. Если Ollama не подключилась: скопируйте из настроек расширения команду OLLAMA_ORIGINS, выполните её в PowerShell, затем полностью закройте Ollama через значок в трее и откройте снова из меню «Пуск». В расширении нажмите «Обновить список моделей».

ОБНОВЛЕНИЕ: распакуйте новую версию поверх СТАРОЙ папки с manifest.json, затем нажмите «Обновить» на карточке расширения в chrome://extensions/ или edge://extensions/. Это сохранит ID расширения и подключение Ollama.

Запросы к модели идут на http://127.0.0.1:11434. Для чтения страницы нажмите «Страница» или одну из быстрых команд. Данные страницы не сохраняются в истории чата. По команде «Зайди на вкладку MAX» расширение переключится на открытую вкладку; если вкладок MAX несколько, выберите нужную из кнопок. «Закрой вкладку MAX» закрывает одну вкладку, «Закрой текущую вкладку» — активную, «Закрой все вкладки MAX» — подходящие вкладки (до 8); закреплённые не закрываются. «Открой сайт MAX» предлагает открыть web.max.ru. Один чёрный указатель Перо виден всё время выполнения запроса: на доступной веб-странице, а если на страницу нельзя вставить указатель — только в панели. Два указателя Перо одновременно не показываются. Он не перемещает системный курсор. Кнопка «Действия» включает агента: чтение страниц, поиск и открытие HTTPS-сайтов, клики и ввод текста. По умолчанию открытие сайта, закрытие вкладки, нажатие и ввод требуют отдельного разрешения. Чтобы убрать эти окна: ⚙ Настройки → Браузерные действия → выключите «Спрашивать подтверждение». Выбор сохраняется; клики могут без запроса отправить сообщение или форму. Защита паролей и платежей остаётся, но не гарантирует безопасность любого сайта. Уже совершённые действия нельзя отменить кнопкой «Остановить». По команде «открой YouTube, найди музыку 2000-х и включи её» браузер открывает YouTube; запрос будет виден сайту, а автовоспроизведение может быть ограничено браузером. Независимый проект, не связанный с Kakadu AI.
