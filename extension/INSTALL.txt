ПЕРО — локальный ИИ для Chrome и Edge

1. Распакуйте этот ZIP в постоянную папку. Рядом с этим файлом должен лежать manifest.json.
2. В Chrome откройте chrome://extensions/ (Edge: edge://extensions/), включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку.
3. Нажмите значок «Перо» на панели браузера. В настройках (⚙) выберите локальную модель Ollama.
4. Если Ollama не подключилась: скопируйте из настроек расширения команду OLLAMA_ORIGINS, выполните её в PowerShell, затем полностью закройте Ollama через значок в трее и откройте снова из меню «Пуск». В расширении нажмите «Обновить список моделей».

Расширение обращается только к http://127.0.0.1:11434. Для чтения текущей страницы нажмите «Страница» или одну из быстрых команд. Данные страницы не сохраняются в истории чата. Независимый проект, не связанный с Kakadu AI.
