ПЕРО 1.5.0 — локальный ИИ для Chrome и Edge

1. Распакуйте этот ZIP в постоянную папку. Рядом с этим файлом должен лежать manifest.json.
2. В Chrome откройте chrome://extensions/ (Edge: edge://extensions/), включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите эту папку.
3. Нажмите значок «Перо» на панели браузера. В настройках (⚙) выберите локальную модель Ollama.
4. Если Ollama не подключилась: скопируйте из настроек расширения команду OLLAMA_ORIGINS, выполните её в PowerShell, затем полностью закройте Ollama через значок в трее и откройте снова из меню «Пуск». В расширении нажмите «Обновить список моделей».

ОБНОВЛЕНИЕ: распакуйте новую версию поверх СТАРОЙ папки с manifest.json, затем нажмите «Обновить» на карточке расширения в chrome://extensions/ или edge://extensions/. Это сохранит ID расширения и подключение Ollama.

Запросы к модели идут на http://127.0.0.1:11434. Для чтения страницы нажмите «Страница» или одну из быстрых команд. Данные страницы не сохраняются в истории чата. По команде «Зайди на вкладку MAX» расширение переключится на открытую вкладку; если вкладок MAX несколько, выберите нужную из кнопок. «Закрой вкладку MAX» закрывает одну вкладку, «Закрой текущую вкладку» — активную, «Закрой все вкладки MAX» — подходящие вкладки (до 8); закреплённые не закрываются. «Открой сайт MAX» предлагает открыть web.max.ru. Чёрный указатель расширения виден, пока Перо выполняет запрос: на доступной веб-странице и в панели, а на служебных вкладках браузера — только в панели. Он не перемещает системный курсор. Кнопка «Действия» включает агента: чтение страниц, поиск и открытие HTTPS-сайтов, клики и ввод текста. По умолчанию открытие сайта, закрытие вкладки, нажатие и ввод требуют отдельного разрешения. Чтобы убрать эти окна: ⚙ Настройки → Браузерные действия → выключите «Спрашивать подтверждение». Выбор сохраняется; клики могут без запроса отправить сообщение или форму. Защита паролей и платежей остаётся, но не гарантирует безопасность любого сайта. Уже совершённые действия нельзя отменить кнопкой «Остановить». По команде «открой YouTube, найди музыку 2000-х и включи её» браузер открывает YouTube; запрос будет виден сайту, а автовоспроизведение может быть ограничено браузером. Независимый проект, не связанный с Kakadu AI.
