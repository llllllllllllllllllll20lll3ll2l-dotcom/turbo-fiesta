Запросы отправляются только на ваш компьютер. Облачные модели и аккаунт не нужны.

Подключение

Адрес: 127.0.0.1:11434. Доступ с других устройств не нужен.

Если соединения нет
  1. Проверьте, что Ollama запущена (значок в трее Windows).
  2. Разрешите доступ только этому расширению командой ниже.
  3. Закройте Ollama через значок в трее и запустите снова из меню «Пуск».

Команда задаёт OLLAMA_ORIGINS для вашего пользователя Windows. Не меняйте OLLAMA_HOST на 0.0.0.0.

Для функции «Страница» браузер запрашивает доступ к сайтам. Перо читает их только по вашему нажатию. Текст страниц не сохраняется в истории. Чаты остаются в хранилище расширения на этом ПК.
