# Aura — локальный ИИ в браузере

Браузерное расширение (Chrome / Яндекс, MV3) для **локальной ИИ**, установленной на вашем ПК.

Чат на русском языке, поиск в интернете и по открытым вкладкам, управление вкладками,
автозаполнение форм из профиля — всё это управляется одной локальной моделью, которая
держится на **Ollama**. Ничего не отправляется наружу.

```
┌─────────────────────────────────────┐
│   Чат в попапе (темная тема)         │
│   ────────────────                   │
│   ● статус Ollama (онлайн/оффлайн)   │
│   ⚡ шаг: поиск …  (история шагов)   │
│   «Найди в интернете о смелости»      │
│   ── отправить ────────────────      │
└─────────────────────────────────────┘
```

## Возможности v1

- **Тёмный чат** на русском, с история и статус модели
- **Поиск** — веб (Яндекс/Google, открывает вкладку и читает результаты)
  и по **открытым вкладкам** (ищет текст на страницах)
- **Вкладки** — открыть новую, закрыть текущую, список активных
- **Автозаполнение форм** — из профиля (имя, телефон, email, город, адрес, дата рождения…),
  а для оставшихся полей — массовый вызов модели
- **Чёрный курсор** — виден только во время ИИ-действия: белый outline + чёрный круг,
  плавно следует за мышью на странице

## Требования

- Chrome 120+ или Яндекс-браузер (MV3)
- Ollama 0.1.40+ (для видео-карты не обязательно — работает и только на CPU)
- Модель, например `qwen2.5:3b` (~2.2 ГБ)

## Установка

### 1. Установите Ollama

Скачайте с <https://ollama.com/download> (Windows / macOS / Linux).

Запустите `Ollama` и проверьте, что он работает:

```bash
ollama list
```

Если ничего не выводится — модель ещё не установлена, переходите к шагу 2.

### 2. Скачайте модель

Для ПК с 4 ГБ видеопамяти и 16 ГБ RAM рекомендована **Qwen2.5-3B Q4_K_M** (~2.2 ГБ):

```bash
ollama pull qwen2.5:3b
```

Другой вариант — `phi3:3.8b` или `gemma3:4b` (больше VRAM). Всё это можно
переопределить в настройках расширения.

### 3. Установите расширение

1. Скачайте/клонируйте этот репозиторий:
   ```bash
   git clone <URL-репозитория>
   cd turbo-fiesta
   ```
2. Откройте `chrome://extensions` (в Яндекс-браузере — `browser://extensions`)
3. Включите **Режим разработчика** (вверху справа)
4. Нажмите **«Загрузить распакованное расширение»**
5. Выберите папку проекта (`turbo-fiesta`)

### 4. Проверка

1. Откройте расширение (иконка в панели)
2. Красная точка → зеленая: Ollama работает и нашла модель
3. Напишите: «Прочитай эту страницу» — увидите шаги и ответ
4. Вкладка «Вкладки» — поиск по открытых страничкам
5. Вкладка «Настройки» — сохраните профиль (имя, телефон, email…)

## Настройки (⚙)

| Поле | Значение по умолчанию |
|---|---|
| `Адрес сервера` | `http://127.0.0.1:11434` |
| `Модель` | `qwen2.5:3b` |
| `Поисковый движок` | `yandex` |
| `Автозаполнение форм` | включено |

В профиле храните: имя, телефон, email, город, адрес, дата рождения, сайт, должность, «о себе».
Поля, которых нет в профиле, заполняются моделью (массовый вызов модели за операцию).

## Архитектура

```
┌─────────────────┐   messages   ┌──────────────────┐   HTTP/JSON   ┌──────────┐
│ src/popup       │◀────────────▶│ src/background   │──────────────▶│ Ollama   │
│  (чат/доки)     │              │  (service worker) │  /api/chat   │  127.0.0.1│
└──────┬──────────┘              └───────┬──────────┘              │ :11434   │
       │                                 │                          └──────────┘
       │ listens                          │ inject / send
       ▼                                   ▼
       ┌────────────────────────────┐   ┌─────────────────┐
       │ src/content (на странице)  │   │ src/lib         │
       │  DOM-чтение, forms, cursor │   │ agent/ollama/   │
       │                            │   │ fields/page     │
       └────────────────────────────┘   └─────────────────┘
```

- `src/lib/` — чистые модули (тестируются юнит-тестами, нода)
- `src/content/content.js` — чтение страницы, заполнение форм, AI-курсор
- `src/background/background.js` — агентский цикл, прокси Ollama, вкладки
- `src/popup/` — темная чат-UI

## Безопасность

- Все запросы идут к **локальному** Ollama (`127.0.0.1:11434`)
- Контентный скрипт только читает DOM, заполняет опционально, не делает `eval`/`innerHTML`
- Форма **не отправляется** автоматически — только заполнение полей
- Страницы, на которых важен пароль, не заполняются (`password` и `hidden` исключены)

## Известные ограничения

- Текст страницы читается через `innerText` — одностраничные приложения (React, SPA)
  могут отдавать неполный текст; это норма для v1
- AI-курсор не отображается на  страницах без content-script-прав (`chrome://`, `about:`)
- Ollama-запрос может занять 5–20 секунд на 4 ГБ VRAM
- Форма НЕ отправляется — заполнение останавливается на этапе «заполнить поля»
- Если вкладка закрылась во время агента — он продолжает работу на др. вкладке
