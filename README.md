# WheelRing — круговой оверлей для Windows

Оверлей, который появляется на экране при нажатии **колёсика мыши** — и показывает круговую
«диаграмму» из блоков. Каждый блок — шаг последовательности: **приложение**
(`notepad.exe`, `chrome.exe`, путь к `.exe`) или **полная команда**
(`start notepad`, `cmd /c copy a.txt b.txt`, `echo привет`…).

Оверлей сохраняет последовательность между запусками и по кнопке «Запустить» запускает
блоки по очереди с настраиваемым интервалом.

## Что умеет

- **Поверх всех окон** (всегда сверху, полупрозрачный тёмный фон, скрытая рамка)
- **Круговая диаграмма** — блоки лежат по кольцу, размер/порядок/тип — вручную
- **Тип блока**: приложение или команда (каждый блок выбирает свой)
- **Добавление / удаление / перемещение** блоков (вперёд-назад по кольцу)
- **Выполнение последовательности** — кнопка «Запустить», текущий блок подсвечивается,
  статус внизу, кнопка «Стоп»
- **Сохранение** — данные в `%APPDATA%\WheelRing\sequence.json` (JSON, можно редактировать вручную)
- **Не требует прав администратора**

## Установка

Windows 10/11 + **Python 3.9+** с модулем `tkinter` (обычно ставится вместе с CPython с python.org).

Всё в одном:

```bat
run_overlay.bat
```

Скрипт начнёт работу в фоне: окно скрыто, и **колёсико мыши в любом месте экрана**
открывает оверлей, повторное нажатие — скрывает его.

> EXE-версия без Python: см. раздел «Сборка EXE» ниже.

## Управление

| Действие | Как |
| --- | --- |
| Показать / скрыть оверлей | **колёсико мыши** (в любом месте экрана), **Esc** |
| Переместить оверлей | зажать шапку и тянуть |
| Выбрать блок | клик по сегменту кольца, или **стрелки ↑ / ↓** |
| Удалить выбранный блок | **Del** |
| Запустить последовательность | **Enter** или кнопка «▶ Запустить» |
| Остановить выполнение | кнопка «■ Стоп» |
| Что делать, если оверлей не снялся с экрана | **⏻** — полная остановка программы |

После добавления блока введите его значение — из поля «Значение»:

- **Приложение**: `notepad.exe`, `calc.exe`, `chrome.exe` или полный путь к `.exe`
- **Команда**: произвольная строка, которая выполнится через `cmd.exe /c`:
  `start notepad`, `cmd /c copy a.txt b.txt`, `echo готово`, `explorer .`

Метка блока (поле «Метка») — это, что будет видно в центре кольца.

Поле «Интервал между шагами» — пауза между последовательными шагами (в миллисекундах).

## Хранение данных

Файл: `%APPDATA%\WheelRing\sequence.json`

```json
{
  "interval": 600,
  "steps": [
    { "name": "Блокнот",  "type": "app", "value": "notepad.exe" },
    { "name": "Команда",  "type": "cmd", "value": "echo Привет от WheelRing" }
  ]
}
```

Файл сохраняется автоматически после каждого изменения и при запуске программы.
Можно редактировать руками — оверлей прочитает его при старте.
Шаги с незаполненным полем «Значение» при запуске последовательности отмечены в статусе.

## Сборка EXE (без Python на машине-пользователя)

Требуется Python 3.9+ и PyInstaller в среде сборки:

```bat
build_exe.bat
```

Будет собран `dist\WheelRing.exe` (один файл, без консольного окна).
Переносимый EXE запускается двойным кликом и не требует установленного Python.

Ручной вариант:

```bat
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name WheelRing --noconfirm wheel_ring.py
```


## Ограничения и примечания

- **Колёсико мыши** перехватывается низкоуровневым хук-кликом (`WH_MOUSE_LL`) — работает даже
  поверх других приложений, без прав администратора. Если вы используете другое приложение,
  которое тоже перехватывает колёсико, поведение может конфликтовать.
- Оверлей **всегда поверх окон** и полупрозрачен (≈96 %) — элементы за ним видны сквозь фон.
- Колёсико в окне оверлея скрывает/показывает оверлей. Если блоки нужно редактировать,
  пишите в поля/кликайте по сегментам — не скролльте колёсиком в самом оверлее.
- Последовательность **запускает реальные приложения и команды** — будьте внимательны
  со строками команд (они выполняются через `cmd.exe /c`, как если бы вы набрав их в терминале).
- При кнопке «■ Стоп» уже запущенные процессы не закрываются — только отмена дальнейших шагов.
- Оверлей скрыт при запуске, но программа не остановлена: колесо мыши в любом месте экрана снова покажет его.
Полная и остановка программы — ⏻ в шапке.

## Журнал ошибок

Если оверлей не открылся или поведение странное, проверьте журнал:
`%APPDATA%\WheelRing\log.txt` (или `%APPDATA%` на 64-битной машине — `Roaming\WheelRing\log.txt`).
Он содержит начало работы, результат установки хукка колёсика и трассировку сбоев.

При запуске через EXE в окне сообщений может ничего не быть — глядя на `log.txt`,
видно, что именно произошло.

## Почему так сделано

Программа использует низкоуровневый хук `WH_MOUSE_LL`, чтобы реагировать на колёсико
**в любой точке экрана**, и **layered window** с прозрачностью, чтобы оверлей был
полупрозрачным поверх остальных окон. Геометрия кольца (сегменты, подписи, центр)
вычисляется чисто математически в `ring_core.py`, что облегчает тестирование.
