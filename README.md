# Перо — локальный ИИ в браузере

Браузерное расширение для Chrome и Edge в спокойном тёмном стиле: чат в родной боковой панели браузера, пересказ/перевод открытой страницы и объяснение выделенного текста. **Работает только с Ollama на вашем компьютере**, без облачного аккаунта. Независимый проект, не связан с Kakadu AI.

## Установка на Windows

1. Убедитесь, что Ollama уже работает и модель скачана. Рекомендуемая модель: `qwen3:4b-instruct-2507-q4_K_M`. В PowerShell проверьте `ollama list`.
2. Скачайте файл `pero-local-ai.zip` из проекта и **распакуйте** в постоянную папку (например, `D:\PeroExtension`). В выбранной папке должен лежать `manifest.json`. Не переносите папку после установки: её адрес влияет на ID распакованного расширения.
3. В Chrome откройте `chrome://extensions/` (в Edge — `edge://extensions/`). Включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и укажите папку с `manifest.json`.
4. Закрепите значок «Перо» на панели браузера и нажмите на него — откроется боковая панель.
5. Если появится сообщение «Ollama недоступна», откройте настройки ⚙ в панели. Скопируйте **показанную там команду** в PowerShell: она подставит настоящий ID именно вашего расширения в `OLLAMA_ORIGINS`.
6. **Полностью закройте Ollama через значок в системном трее Windows** (пункт «Выход»/Quit), затем откройте её заново из меню «Пуск». Вернитесь в настройки панели и нажмите «Обновить список моделей». При необходимости перезапустите браузер.
7. В настройках выберите `qwen3:4b-instruct-2507-q4_K_M`. Если установлена только другая модель, расширение выберет её автоматически.

`OLLAMA_ORIGINS` нужен потому, что Ollama по умолчанию не разрешает запросы с адресов браузерных расширений. Команда из панели разрешает **только это расширение**, а Ollama остаётся на `127.0.0.1:11434`; не открывайте Ollama в локальную сеть через `OLLAMA_HOST=0.0.0.0`.

Если у вас уже был свой `OLLAMA_ORIGINS`, не заменяйте его вслепую: объедините нужные адреса по документации Ollama. Команда в панели задаёт переменную пользователя Windows, а не системную переменную. Если Ollama работает как отдельная системная служба под другой учётной записью, её окружение придётся настроить отдельно.

## Как пользоваться

- Обычный чат: введите вопрос, Enter — отправить, Shift+Enter — новая строка. Кнопка ■ прерывает генерацию.
- **Страница**: включите кнопку над полем ввода. При каждом вашем отправленном вопросе расширение возьмёт фрагмент текста текущей страницы. Кнопка «Кратко пересказать страницу» делает это сразу.
- **Выделение**: выделите текст в открытой вкладке, нажмите «Выделение» или «Объяснить выделенный текст». Выделенный фрагмент добавляется к следующему вопросу.
- «Новый чат» удаляет локальную историю беседы в расширении. Выбранная модель сохраняется.

Веб-страницы и выделенный текст **не сохраняются в истории чата**; они передаются локальной Ollama только после вашего действия. История вопросов и ответов хранится в `chrome.storage.local` на вашем ПК. Текст некоторых сайтов, служебных страниц браузера (`chrome://`, `edge://`) и защищённых PDF-файлов получить нельзя. Большие страницы обрезаются до 4800 символов, выделение — до 2600: это ограничение для 4 ГБ видеопамяти и контекста 4096 токенов. Версия 1.0 работает с **текстом** — изображения, видео, голос и OCR пока не поддерживаются.

## Безопасность и доступы

`sidePanel` — боковая панель; `storage` — настройки/история; `tabs` и `scripting` — чтение текущей вкладки **только по запросу**; доступ к HTTP/HTTPS-сайтам — для анализа открытой страницы; `127.0.0.1:11434` — локальная Ollama. Расширение не отправляет данные на сторонние серверы и не загружает удалённый код. Не вставляйте пароли или секреты в обычный текст страниц для анализа. Если включите облачную модель в Ollama вместо локальной, запросы перестанут быть полностью локальными.

## Разработчику

Это Manifest V3 без сборки, зависимостей и сторонних библиотек. `extension/` — папка, устанавливаемая в браузер; `core.mjs` содержит независимую от браузера логику построения запроса и разбора потока Ollama. Проверки: `node --test tests/*.test.mjs` и `node --check extension/panel.js`.
